# C盘爆满，从D盘扩容的完整踩坑记录

## 一、我的电脑情况

- **磁盘1（SSD，238.46GB）** 分区结构：
  - 260MB EFI 系统分区
  - **C盘（Windows-SSD）：99.16GB → 目标扩容**
  - 855MB 恢复分区（挡在C和D中间）
  - **D盘（Data）：137.23GB**
  - 1000MB 恢复分区
- E盘是另一块机械硬盘，和C/D不在同一物理磁盘，无法直接划给C盘。
- C盘爆满，D盘当时只剩16.8GB可用。

## 二、核心结论（先看这个）

1. **跨物理磁盘不能直接扩容**：E盘机械盘和C盘不在同一块盘上，不能直接划空间。
2. **同一块盘可以扩容，但有前提**：C盘和D盘中间隔着855MB恢复分区，Windows自带“扩展卷”会灰掉，必须用第三方工具（傲梅/DiskGenius）。
3. **正确姿势是用“扩容分区”功能**：不要先手动分出一个F区再合并，那样中间隔着恢复分区会合并不了。
4. **D盘空间不足时先清理**：D盘只剩16.8G时压缩不出多少空间，清到31G可用后才勉强能压出约20G。
5. **分区操作中途死机会导致空间“失踪”**：重启后D盘少了20G，C盘没收到，多出一块20G未分配空间。

## 三、完整操作流程

### 步骤1：判断E盘能不能划给C盘

打开“磁盘管理”（Win+X → 磁盘管理）：
- 看C盘和E盘是否在同一个“磁盘X”下。
- 不在同一块物理盘 → 不能直接划。
- 在同一块盘但中间隔着分区 → 需要第三方工具。

### 步骤2：清理D盘，腾出可压缩空间，因为我D盘有些东西没用 可以清理出来

- D盘只剩16.8G可用时，压缩卷压不出多少。
- 把D盘里的大文件（视频、安装包、备份）挪到E盘。
- 清到**31GB可用**后，才勉强能压出约20G。


### 步骤3：用傲梅分区助手扩容C盘（正确方式）

1. 下载安装傲梅分区助手（免费版够用）。
2. 选择**D盘**后右边会有分配空闲空间
3. 弹窗里面选择好自己需要分配的空间大小 然后有个从某个盘分多少给某个盘的选项
4. 然后点“确定”。
<image src="/uploads/1790773299095.png">

5. 因为涉及C盘（系统盘），软件提示**需要重启**，在进入Windows前的PreOS环境执行。

### 步骤4：重启执行

- 重启后进入蓝底/黑底的PreOS界面，有进度条。
- **不要强制关机**，等它跑完自动进系统。
- 跑完后打开“此电脑”，C盘容量应已变大。

### Q1：如果中途死机，恢复空间

死机后重启，可能出现：
- C盘没扩成功
- D盘少了20G
- 多出一块20G“未分配空间”

处理方式：
1. 先打开“磁盘管理(快捷键 win+X)”确认现状。
2. 如果C盘已经变成119GB → 说明扩容部分成功，那20G是多余的，还给D盘即可。
3. 如果C盘还是99GB → 那20G未分配需要重新用“扩容分区”给C盘。
4. **千万不要右键未分配空间点“新建简单卷”**，会覆盖数据。

### Q2：把多余空间还给D盘

1. 傲梅里右键**D盘** → “调整/移动分区”。
2. 把D盘右侧滑块往右拉，吃掉未分配空间。
3. 提交执行（不涉及C盘，通常不用重启）。

## 四、我电脑上的踩坑问题总结

| 问题 | 原因 | 解决办法 |
|------|------|----------|
| E盘不能划给C盘 | 不在同一物理磁盘 | 只能清理或换盘 |
| “扩展卷”是灰的 | C和D中间隔着855MB恢复分区 | 用傲梅/DiskGenius |
| D盘压不出空间 | D盘只剩16.8G，空间不连续 | 先清理到30G或者20G左右以上 |
| 手动分F区后合并不了C盘 | 未分配空间和C盘中间隔着恢复分区 | 别手动分，直接用“扩容分区” |
| 分区中途死机，空间失踪 | 分区表操作中断 | 用“分区恢复”或手动还空间 |
| 重启后C盘没变大 | PreOS执行中断 | 检查磁盘管理，重新扩容 |
| 未分配空间不敢动 | 怕点“新建简单卷”覆盖数据 | 只做“调整/移动分区”合并 |

## 五、最终结果

- C盘：99.16GB → **119.16GB**（成功扩容20G）
- D盘：137.23GB → 97.23GB（被借走20G）
- 多出一块20G未分配空间，需还给D盘
- D盘剩余空间：26.92GB

## 六、经验教训

1. **分区前一定备份重要数据**。
2. **操作前关掉杀毒软件、下载工具、微信等**，避免死机。
3. **系统盘扩容必须用第三方工具**，因为Windows自带功能太死板。
4. **优先用“扩容分区”而不是“先分再合”**。
5. **D盘/E盘空间规划要合理**：C盘只装系统，软件装D盘，大文件放E盘机械盘。
6. **微信/QQ文件目录改到其他盘**，这是C盘爆满的最大元凶之一。
7. **关闭休眠**：管理员CMD运行 `powercfg -h off` (实在没办法可以尝试)，能释放几G到十几G。

---

**一句话总结**：C盘扩容用傲梅“扩容分区”直接借D盘空间，别手动分F区；中途死机别慌，先看磁盘管理，未分配空间别点“新建简单卷”，用“调整/移动分区”还给D盘即可。
