封面方案对比

用你真实的 4 篇文章、真实的卡片尺寸渲染。下面 6 个候选保留为选型记录。

已实施（2026-09-23）：采用「深色打字机 + 首词排版」两轨制
  • 标签命中 AI / 工程 / 前端 / 后端 / 开发 / 技术 / 算法 → 深青绿终端轨，底色 #0d3a34（压深两档的青绿，不是纯黑也不是蓝黑）
  • 其余 → 浅色轨：实底 + 白字 —— 大号衬线首词（frontmatter 的 kicker，缺省回落到第一个标签）压在标签派生的实色块上，右上角一个白色几何符号
  • 浅色轨的底色就是站点 6 套 accent 的 500 档（如青绿 #1aa88f），两种明暗模式共用一个值；两条轨靠明度拉开而不是靠色相，见 cover-preview-light.png / cover-preview-dark.png
  • 标签取色默认按名称 hash 自动分配，另有显式指定表纠偏：设计 → 青绿（hash 本来落在石墨灰，灰度封面在网格里最不抢眼，且与站点默认主色不一致）

即下面候选 5「深色打字机」与候选 6「首词排版」的组合，其余候选未采用。 候选 6 的底色在实施后改过一轮：最初按「浅底 + 同色字」铺（青绿那档是 #eefbf7 底 + #0f8773 字）， 实际看下来太淡、撑不住大号衬线字，遂统一成实底 500 档 + 白字；终端轨也由原来的深黑蓝改成深青绿，让两条轨落在同一个色系里。

为什么要换——现在这版有三处结构性问题，不是配色不好看的问题：
  1. 随机色 + 取标题前 2 字。「给智能体装上记忆」→ 显示「给智」，这是截断，不是设计；而且色板是 8 组彩虹色，和站点 accent 色阶（6 套预设）是两套系统，互相打架。
  2. 信息密度为零。18rem 的头条封面占了首屏最大一块面积，却不承载任何信息。
  3. 不可扫描。色块由标题 hash 决定，所以「设计」类和「AI」类文章的颜色毫无规律，首页网格里看不出任何分类线索。
